# Trascrizione Riunioni

Pagina web per trascrivere in tempo reale (in italiano) quello che viene detto durante una riunione.

**Link:** https://gcernu31.github.io/trascrizione-riunioni/

Funziona con Google Chrome o Microsoft Edge (PC o Android). Serve internet e il permesso del microfono. A fine riunione il pulsante "Scarica Word" salva un file .docx.
